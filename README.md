# Jeu de Devinettes 

## Description
Un jeu en Java où l'ordinateur génère un nombre aléatoire entre 1 et 100.
Le joueur a 10 essais pour deviner le nombre secret.

## Règles
- Le nombre secret est entre 1 et 100
- Le joueur a 10 essais maximum
- Des indices sont donnés après chaque essai
- Le joueur gagne s'il trouve le nombre avant la fin des essais

## Comment jouer 
1. Lancer le programme
2. Entrer un nombre entre 1 et 100
3. Suivre les indices jusqu'à trouver le nombre

## Technologie
- Java 21
